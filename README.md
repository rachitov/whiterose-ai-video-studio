# Whiterose AI Video Studio (starter)

Modules: frontend/ (page) -> backend/ (Express API) -> Supabase Auth and Database, with providers/ (adapters).

Run: `npm install`, copy `.env.example` to `.env`, fill in `SUPABASE_URL` and `SUPABASE_ANON_KEY`, run `database/supabase.sql` in the Supabase SQL Editor, then `npm start` and open http://localhost:3000.

## Deploy on Render

This is a Node.js web service, not a static GitHub Pages site. After pushing the project to GitHub, create a Render Blueprint from the repository and select `render.yaml`. Render builds with `npm ci`, starts with `npm start`, and checks `/api/health`. Enter secrets in the Render service environment settings only; `.env` is local and must never be committed. Supabase URL and anon key are required for sign-in and saved projects. After the service is created, add only the provider keys you intend to use in its Render Environment settings; those secret values are not stored in the Blueprint. Rotate any API key that has been exposed outside the provider dashboard.

The Blueprint uses Render's free web-service plan. Free instances can sleep when idle and their local filesystem is ephemeral; SQLite-backed generation-job history can be lost after a restart or redeploy. User projects are stored in Supabase. Confirm current Render pricing and limits before changing to a paid plan.

Works now: email/password registration and demo sign-in through Supabase Auth, user-owned project storage, Magic Hour and Gemini Veo video generation, Higgsfield Seedance 2.5 text-to-video, OpenAI GPT Image generation, Gemini Nano Banana image generation, and Higgsfield SOUL image generation. Video generation takes its directions directly from the prompt; it does not require AI storyboard planning.

The Create page starts with a single image-or-video choice; selecting Video reveals the text-to-video and image-to-video workflows, while selecting Image reveals image generation and original local SVG preview cards for portrait, product, travel, and food prompts. Selecting a card fills an editable prompt and suggested aspect ratio; the illustration is only a visual preview, not a generated result. The image studio also includes a free, browser-local SVG illustration generator. It sends no prompt to a provider, consumes no API credits, and needs no model setup; its output is stylized vector art rather than photoreal AI. There is no guaranteed free hosted AI image API. Bing Image Creator, ChatGPT, Leonardo.ai, and Hugging Face Spaces are offered as external website handoffs: Whiterose copies the prompt and opens the site, but the user must submit the prompt there. Login requirements, free tiers, and availability are controlled by each site.

OpenAI image generation is available in the signed-in Create section. Set `OPENAI_API_KEY` in the server `.env` file and restart the app. It uses the OpenAI Images API with `gpt-image-2.5-flare`, medium quality, and square/landscape/portrait output sizes. OpenAI API usage is billed according to the account's model pricing; the app requires explicit paid-use confirmation but does not quote the request price. The key remains server-side. The login page does not include an image generator.

To enable video generation, set `MAGIC_HOUR_API_KEY` in the server `.env` file and restart the app. The legacy `MAGICHOUR_API_KEY` variable is also accepted. Keep either key server-side; never put it in the browser or commit it. Video jobs are associated with the signed-in Supabase user and their status is stored in `database/studio.db`. The app supports Magic Hour text-to-video and image-to-video with JPG/PNG references, 3–30 second clips, and selectable aspect ratios. It explicitly requests 480p output to support subscription tiers that do not include 720p. Reference images are uploaded to Magic Hour's signed upload URL; the permanent API key is not sent to that URL. Download links are temporary, so download completed videos promptly. Generation spends provider credits; check your account balance and current pricing before confirming a job.

Higgsfield uses a server-side API key ID and secret, configured as `HIGGSFIELD_API_KEY=KEY_ID:KEY_SECRET` in `.env` (or as `HF_API_KEY_ID` and `HF_API_KEY_SECRET`). The app supports Seedance 2.5 text-to-video (4–30 seconds) and SOUL standard text-to-image. Higgsfield image-to-video is not wired because its API requires a publicly accessible reference-image URL; no image host is configured. The app asks for explicit paid-credit confirmation before either Higgsfield workflow, but does not check or quote the account balance. Higgsfield returns temporary media URLs; download completed outputs promptly.

The Video Director composes the user prompt with clip duration, language, aspect ratio, and text-to-video or image-to-video mode before submission. Use **Preview generation prompt** to review it without spending generation credits. An Anthropic key is not required for video generation.

Prompt direction favors one visible action with a clear start and finish; for image-to-video it treats the supplied still as the source of truth and directs motion without redesigning it. Completed outputs are not automatically quality-approved: use the review checklist below each generated image/video to check the actual result, including framing, visual consistency, duration, and audio where present.

Gemini video generation uses the `GEMINI_API_KEY` server environment variable (the optional alias is `GOOGLE_GEMINI_API_KEY`) and Veo 3.1. Veo generates 8-second clips at 720p, in 16:9 or 9:16; Google account/API availability and billing apply. Gemini image generation uses the Nano Banana Interactions API; quota and billing depend on the Google AI Studio project. Generated video bytes are fetched through an authenticated app endpoint so the Gemini key is never exposed to the browser. Google Flow ([flow.google.com](https://flow.google.com/)) is not exposed as a public generation API; the app offers a prompt-copy/open-Flow handoff, and the user must upload any reference image and submit the job in Flow themselves.

If Gemini responds with `RESOURCE_EXHAUSTED`, HTTP 429, or a quota/billing message, check the Google AI Studio project selected by the API key at [Billing](https://aistudio.google.com/billing) and [Rate limits](https://aistudio.google.com/rate-limit). The app displays this guidance and does not retry generation automatically; wait for a quota reset, resolve billing/credits, or switch the provider to Magic Hour.

The app has native equivalents for the core intake, generation, and status-polling path (`POST /api/video/generate`, `GET /api/video/status?request_id=...`); it does not import or execute the n8n JSON. Paid generation starts immediately after the user confirms usage in the app; the status response does not include a live budget quote. n8n itself, Google Sheets/Drive, and its Data Tables are not required for app-native generation. The Intake workflow references a separate "WR – AI Director (Storyboard)" subworkflow that was not supplied, and the provided workflows do not include a multi-scene video compositor. Therefore, the app currently generates individual clips rather than assembling the workflow's planned 60–180 second videos. The original bulk workflow's Google Sheets/Drive OAuth credentials are also not included.

Demo login creates a Supabase anonymous Auth user, so demo projects are saved to Supabase under that user's ID and protected by row-level security. Enable anonymous sign-ins in the Supabase dashboard under Authentication → Sign In / Providers. Run `database/supabase.sql` once in the SQL Editor to create the projects table and row-level security policies. Demo sessions belong to that browser/device; signing out and creating a new demo session creates a separate anonymous user.

Use the Supabase project's URL and publishable/anon key only. Never expose its service-role key in the frontend or `.env` values committed to source control. Enable email/password in Supabase Auth; if email confirmation is enabled, new users must confirm before signing in.
